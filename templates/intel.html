{# ── Tab: Devices ── #} {% elif tab == 'devices' %}

Device-ID Leaderboard?Senders ranked by how many distinct Signal device IDs they've used. A high count can mean: multiple linked devices (phone + desktop + iPad), account re-registrations (each re-reg can cycle device IDs), or an account operated from several endpoints. The Distinct Names column shows how many different display names the sender has used — name changes are derived from per-message sender_name history. A UUIDs > 1 row means the same phone number has been seen with more than one Signal ACI — a rare, strong signal of account replacement.

Requires Phase 1 envelope capture: pre-capture messages have NULL source_device and aren't counted.
